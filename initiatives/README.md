# Initiatives

One file per initiative from the quarterly plan, named `NN-short-name.md`, created when work starts and
closed with an outcome section when it ends. Six are planned for Q4 (see `plan/2026-q4.md`); none has a
file yet because the tooling decision comes first.

A file has four sections: why, done when, approach, outcome. Keep "approach" honest; if it is a script,
link it; if it is a tool, say which and what it cost. Data produced by an initiative goes to `data/` with a
suffix and never replaces an export.
